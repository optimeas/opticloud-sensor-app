# What's New

This page lists every version of the app for iOS, newest first.

## Welcome and what's new in the app

- At its first start, the app greets you with a **welcome screen**. It shows in a few points what the app can do. **Get Started** takes you on to the sign-in.
- After an update, the app shows **What’s New in optiCLOUD Sensor** once, with the most important changes of the version. **Continue** closes the screen. New builds of the same version do not show it again.
- You find both screens at any time under **Settings** → **About optiCLOUD Sensor**: **Welcome** and **Version History**. In the version history, each change is marked as new (✦), improved (↑), or fixed (wrench).

## Version 0.8.0

October 27, 2026

- **New:** The tab Favorites shows the default dashboard, your favorites from the web application, and favorites of your own, and opens them signed in. See [Favorites](favorites.md).
- **New:** Quick note from the live view. The title is optional; without one, the note takes the first line of the text. See [Notes](notes.md).
- **New:** Siri and the Shortcuts app: “New optiCLOUD Note” saves a dictated note without opening the app.
- **New:** Notes wait without a network or sign-in and are sent later. The Diagnosis tab shows them.
- **New:** Welcome screen, this overview of what is new, and the version history.
- **Fixed:** The app no longer stops when the connection drops while data arrives, for example on a train.
- **Fixed:** The tenant stays shown after choosing a device.
- **Fixed:** The list of devices shows only the devices of the chosen project.

## Version 0.1.0 (build 74)

October 26, 2026

- **Improved:** Sending in the background goes on with the screen locked, with fresh positions.
- **New:** Test signal to check in optiCLOUD that every value has arrived.
- **Improved:** The diagnosis log is kept when the app restarts.
- **Fixed:** The log no longer shows the identifier of the installation.

## Version 0.1.0 (build 66)

October 26, 2026. The first version on TestFlight.

- **New:** Sign in to optiCLOUD and choose the device of this phone.
- **New:** Sensors for motion, environment, location, activity, the device, and sound.
- **New:** Sending in the background and an offline queue that delivers the values later.
- **New:** Commands and settings from optiCLOUD, and the data volume of the app.
- **New:** Diagnosis with log and test values, in five languages, with a user manual.
